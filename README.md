# Mahlvori Privacy

Bilingual, static, tracker-free privacy and help site for the upcoming Mahlvori Android editions. GitHub Pages site source: `https://github.com/appsmakerdeluxe/mahlvori-privacy`.

- German Free policy: `https://appsmakerdeluxe.github.io/mahlvori-privacy/privacy/`
- German Pro policy: `https://appsmakerdeluxe.github.io/mahlvori-privacy/privacy/pro/`
- English Free policy: `https://appsmakerdeluxe.github.io/mahlvori-privacy/en/privacy/`
- English Pro policy: `https://appsmakerdeluxe.github.io/mahlvori-privacy/en/privacy/pro/`
- Product data and licenses: `https://appsmakerdeluxe.github.io/mahlvori-privacy/catalog/` (English: `/en/catalog/`)

Both apps are currently unreleased. These policies describe the planned app behavior and must be reviewed against each shipped binary, its final SDK inventory, and Play declarations before submission. The product site identifies that status and makes no claim of a live service.

The site has no scripts, analytics, advertising, cookies, external fonts, pixels, or embedded third-party media. It publishes the derived DACH Open Food Facts catalog with ODbL/DbCL attribution and a downloadable copy. GitHub Pages itself may process visitor IP addresses for security. It is a policy website; the app's personal recipe, allergy, pantry, price, and household information remains on the user's device under the specified design.
