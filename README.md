# Mahlvori Privacy

Bilingual static privacy and help site with no site analytics or advertising scripts for the upcoming Mahlvori Android app. GitHub Pages site source: `https://github.com/appsmakerdeluxe/mahlvori-privacy`.

- German Free policy: `https://appsmakerdeluxe.github.io/mahlvori-privacy/privacy/`
- English Free policy: `https://appsmakerdeluxe.github.io/mahlvori-privacy/en/privacy/`
- Product data and licenses: `https://appsmakerdeluxe.github.io/mahlvori-privacy/catalog/` (English: `/en/catalog/`)

The app is currently unreleased. The Free development build uses the bundled Google ML Kit barcode SDK; Google documents technical diagnostic and usage metrics sent to Google, and the resolved Free manifest currently includes Internet and network-state permissions from SDK dependencies. Reconcile this with the intended privacy design, then review the final build and Play declarations before submission. The product site identifies the unreleased status and makes no claim of a live service.

The site source adds no JavaScript, its own analytics or advertising, external fonts, pixels, or embedded third-party media; it does not set analytics cookies. It publishes the derived DACH Open Food Facts catalog with ODbL/DbCL attribution and a downloadable copy. GitHub Pages itself may process visitor IP addresses for security. It is a policy website; the app's personal recipe, allergy, pantry, price, and household information remains on the user's device under the specified design.
